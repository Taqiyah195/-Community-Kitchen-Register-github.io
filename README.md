Community Kitchen 🍲

A simple and user-friendly web project created to promote community food support and social awareness.

📝 About the Project

The Community Kitchen project is a website that highlights the importance of community service and providing food support to people in need. It is designed with a clean and simple interface for easy navigation.

🛠️ Technologies Used
HTML
CSS
JavaScript
✨ Features
User-friendly design
Easy navigation
Informative content
Interactive web elements
Responsive layout
